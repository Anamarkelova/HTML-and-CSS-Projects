# HTML and CSS Projects
This repository contains the projects I completed during The Tech Academy's HTML and CSS course. Throughout this course, I learned how to build responsive webpages using HTML and CSS, create navigation menus, style web pages, and publish projects using GitHub.

## Projects

### Academy Cinemas
A movie theater  website built with Bootstrap. This project includes responsive layouts, navigation, cards, and forms.

### Simple Recipes Website
A recipe website created using HTML and CSS. It features a navigation menu, recipe section, an About section, and a contact form.

### One-Page Travel Website
A one-page website showcasing travel destinations with images, navigation links, a video, and a contact form.

### Portfolio Website
A personal portfolio website highlighting my background, web development skills, projects, GitHub profile, and contact information.

### CSS Effects Challenge
A project demonstrating CSS styling techniques such as hover effects, custom fonts, transitions, and image effects.
